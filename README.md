# SATRailGuide

Site vitrine de départ pour SATRailGuide.

## Fichiers
- `index.html` : structure et contenu de la page d'accueil
- `styles.css` : apparence et mise en page responsive
- `script.js` : menu mobile, année automatique et filtres de démonstration
- `assets/logo.svg` : logo provisoire

## Publication
Ce projet est prévu pour être publié avec Cloudflare Pages depuis un dépôt GitHub.
La connexion à Supabase sera ajoutée dans une étape ultérieure.

## À personnaliser avant publication
- Remplacer les parcours de démonstration par des informations vérifiées.
- Remplacer les images temporaires par des photographies autorisées.
- Ajouter les coordonnées de contact réelles.
- Configurer Supabase avant d'activer les fonctionnalités dynamiques.

Les cartes et événements actuellement affichés sont des exemples de présentation, pas des itinéraires réels.
